Connect to GitHub

Paste your GitHub access key once on this device. It is stored only in this browser.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Repository access: Only select repositories → md1-notes-site.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate the key, copy it and paste it here.
